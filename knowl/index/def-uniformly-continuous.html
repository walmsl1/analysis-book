Definition 0.7.3 Uniform continuity.

Let \(A\subseteq\operatorname{dom}(f)\text{.}\) The function \(f\) is uniformly continuous on \(A\) if
\begin{gather*} \forall\,\epsilon\gt 0\ \exists\,\delta\gt 0 \text{ s.t. } \boxed{\forall\, a\in A}\\ \forall\, x\in A \text{ with } |x-a|\lt\delta,\ |f(x)-f(a)|\lt\epsilon. \end{gather*}
