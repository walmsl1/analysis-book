How the explorer finds the largest δ

Fix ε. The δ's that work at a are exactly the numbers in (0, δ*], where δ* = inf{ |x − a| : x ∈ dom(f) and |f(x) − f(a)| ≥ ε }, the distance from a to the x's where the graph is outside the ε-band or on its edge. If there are no such x, every δ works. So the explorer looks for where those x's begin on each side of a.

It never solves an equation. It uses interval arithmetic: for a whole interval of x-values at once, it computes guaranteed lower and upper bounds for f(x). When the bounds fit inside the ε-band, the whole interval is cleared. Otherwise the interval is split in half, and the halves are checked in order, moving outward from a. The result is accurate to about nine significant digits, and the δ shown is rounded down, so it works. Because whole intervals are checked, the search does not miss narrow spikes the way checking a few hundred points can.

With Use only x in A checked, only x ∈ A count, as in the definition: f is uniformly continuous on A if for all ε > 0, there exists δ > 0 such that for all a, x ∈ A with |x − a| < δ, |f(x) − f(a)| < ε.

Zooming: scroll on the graph (or pinch on a trackpad). Hold Shift to zoom only the x-axis, or Alt/Option to zoom only the y-axis; the + and − buttons work the same way. Shift-drag stretches the graph away from where you grab it; start the drag on an axis to stretch just that axis. ⌂ returns to the starting view.

Drawing the graph: f is sampled four times per pixel, and peaks and jumps are pinned down by bisection. Where the graph turns around more than once inside one pixel column (like sin(1/x) near 0), that column is filled from the guaranteed minimum to the guaranteed maximum of f over it, using the same interval arithmetic.

Functions: ln is the natural log and log is base 10. x^(1/3) is the real cube root, also for x < 0. Multiplication can be implied: 2x, x sin(1/x), and 1/2x means 1/(2x). Check the “read as” line to see how a formula was understood.
